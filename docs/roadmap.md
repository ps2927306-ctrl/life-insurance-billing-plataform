# Roadmap

## Completed in the pilot

- Browser-based operational workflow.
- Multi-file spreadsheet import.
- Identifier normalization and text-safe export.
- Real-time validation and safe automatic correction.
- Configurable company rules and calculation models.
- Layout generation, including sub-invoice handling.
- Three-way reconciliation and invoice verification.
- Local state recovery and monthly checklist.

## Next product iterations

### Reliability

- Add unit tests for normalization, validation, exclusion detection, and calculation rules.
- Create anonymized fixture workbooks for regression testing.
- Add an explicit change log for business-rule configuration.

### User experience

- Add an onboarding guide and contextual help.
- Improve exception explanations and downloadable validation evidence.
- Add accessibility checks and keyboard navigation coverage.

### Scale and governance

- Consider authenticated multi-user access and a shared configuration store.
- Add versioned configurations, audit history, and approval controls.
- Evaluate a secure backend for high-volume processing or centralized reporting.

### Portfolio presentation

- Add anonymized screenshots for all six modules.
- Record a short, sanitized demo video or GIF.
- Add an anonymized BPMN diagram illustrating the before-and-after process.
